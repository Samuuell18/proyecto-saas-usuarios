# Documentación del proyecto

Bundle OKF (Open Knowledge Format): Markdown con frontmatter que describe el proyecto tal como está en el repositorio. Se generó el 2026-10-30 para el Sprint 1 a partir del código, el historial de git y `gh`, y se ha mantenido en cada pull request del Sprint 2 (cerrado el 2026-11-17). La app se llama **Forja** desde el 16-nov (antes, Fitness Hub). Las marcas `TODO(alumno)` son motivos y reflexiones pendientes; "Por verificar" marca lo que no se pudo comprobar. Visión general del proyecto en el [README](../README.md).

- [log.md](log.md): cronología del proyecto, del más reciente al más antiguo.
- [arquitectura.md](arquitectura.md): capas, fronteras exactas y endpoints.
- [requisitos.md](requisitos.md): estado de cada requisito con su evidencia.
- [decisiones.md](decisiones.md): decisiones de diseño, con su motivo y su estado.
- [procesos.md](procesos.md): flujo de trabajo, CI y despliegue continuo.
- [sprint-1.md](sprint-1.md): un apartado por hito y retrospectiva.
- [sprint-2.md](sprint-2.md): MVP de Forja, plan por hitos, avance de cada PBI, cierre y retrospectiva.
